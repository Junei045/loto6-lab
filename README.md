# ロト6 分析＆予測ラボ

過去10年分（約1,030回）のロト6当せん番号を集計・可視化し、
「統計で当せん番号は予測できるか？」を自分の目で確かめられる教材アプリです。

公開URL: https://junei045.github.io/loto6-lab/ （GitHub Pages 有効化後）

## できること
- 出現回数 1〜43 と期待値の比較、カイ二乗検定による「偏りは偶然の範囲か」の判定
- ホット／コールドナンバー、奇偶バランス、合計値分布、連番率
- 候補番号ジェネレーター（頻度重視／直近トレンド／バランス型／完全ランダム）
- 当せん確率の理論値（1等 1/6,096,454 など）
- **買われやすさ指数**: みずほ銀行公表の5等当せん口数から、各数字が「どれだけ買われているか」を回帰で推定
  （パリミュチュエル方式なので、当せん確率は不変でも当せん時の分け前に影響する）
- 「⑤ 分け前重視」モード: 買われにくい数字に重みを付けて候補を生成
- **バックテスト**: 各モードを過去200回に適用し、実際の当せん番号との一致数を実測
  → どのモードも理論値 0.837個/口 とほぼ同じになる＝統計で当せん確率は上がらないことが体験できます

## データ更新
`update_loto6_data.py` が [KYO's LOTO6](https://loto6.thekyo.jp/) の公開CSVを取得し、
`data/draws.js` `data/stats.js` `data/stats.json` を再生成します。

GitHub Actions（`.github/workflows/update-data.yml`）で毎週月・木の夜に自動実行され、
変更があれば自動コミットされます。手動実行は Actions タブ →「ロト6データ自動更新」→ Run workflow。

ローカルで更新する場合（numpy が必要）:
```
pip install numpy
python update_loto6_data.py
```

## 注意
ロト6の抽せんは独立したランダム事象であり、本アプリは統計の可視化と学習を目的としています。
当せんを保証・予知するものではありません。データ元: KYO's LOTO6（公式抽せん結果に基づく公開データ）。
